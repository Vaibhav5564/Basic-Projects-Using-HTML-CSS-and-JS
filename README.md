# 🌐 HTML, CSS & JavaScript Mini Projects Collection

This repository contains a collection of beginner-friendly web development projects built using **HTML5**, **CSS3**, and **JavaScript**. These projects were developed to strengthen core frontend development skills such as DOM manipulation, event handling, responsive design, animations, and JavaScript logic.

Each project focuses on solving a different problem while improving practical knowledge of modern web development.

---

## 🚀 Projects Included

### 🎮 Tic Tac Toe
A two-player Tic Tac Toe game featuring winner detection, draw detection, and game reset functionality.

### 💱 Currency Converter
A currency conversion application that converts values between different currencies using exchange rate APIs.

> **Note:** Live currency conversion requires a valid API key. The project structure and API integration are implemented; users can add their own API key to enable real-time exchange rates.

### ✊ Stone Paper Scissors
An interactive game where users play against the computer with automatic score tracking and random move generation.

### 🦖 Dino Game
A browser-based endless runner game inspired by the Chrome Dino game, including obstacle collision detection and score tracking.

### 🕒 Analog Clock
A real-time analog clock that displays the current system time using JavaScript.
